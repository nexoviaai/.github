# Security Policy

We take the security of Nexoviaai and our customers' data seriously.

## Reporting a vulnerability

Please email **security@nexoviaai.com** with:

- A description of the issue and its potential impact
- Steps to reproduce (proof-of-concept if available)
- Any affected endpoints, repositories or versions

Please **do not** open a public issue for security reports. We aim to acknowledge reports within 3 business days and will keep you updated as we investigate.

## Scope

This policy covers all repositories under the `nexoviaai` GitHub organization and services at `*.nexoviaai.com`.
